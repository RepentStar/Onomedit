# Rust 性能基线

## 用途

本基线覆盖 Rust 切换前约定的四个风险场景：大目录收集、10,000 项计划、长路径和大日志读取。它用于在同一台机器、同一构建配置下比较后续改动，不作为跨机器的绝对性能承诺。

测试被标记为 `ignored`，避免常规单元测试创建 10,000 个文件。使用 release profile 串行运行：

```powershell
cargo test --locked --release -p onomedit-core --test performance_baseline -- --ignored --nocapture --test-threads=1
```

测试会在系统临时目录创建隔离数据，并在结束时自动清理。计时不包含 Cargo 编译时间；大目录测试会单独报告造数时间。

## 2026-08-25 Windows 基线

环境：

- Windows NT 10.0.26200.0，x86-64；
- Intel Family 6 Model 140，8 个逻辑处理器；
- `rustc 1.98.0 (88d9e12ae 2026-08-18)`；
- `--release`，单测试线程，本机临时磁盘。

| 场景 | 规模 | 耗时 |
| --- | ---: | ---: |
| 构造大目录测试数据（不计入核心流程） | 10,000 个空文件 | 5,449 ms |
| 目录展开、名称排序及 UTF-8 临时编辑文件准备 | 10,000 项 | 845 ms |
| 纯计划生成 | 10,000 对路径 | 2 ms |
| 长路径 prepare + plan | 252 个字符 | 1 ms |
| 历史日志读取与解析 | 1,860,000 字节 / 20,000 对 | 10 ms |

首次记录的完整测试体耗时为 8.80 秒，主要由测试数据创建和清理占用。

## 比较规则

- 只比较同一机器、release profile、串行测试的结果；磁盘、杀毒软件和系统负载会显著影响目录场景。
- 至少运行三次并使用中位数判断回归；单次结果只用于建立数量级。
- 如果稳定中位数比本基线慢 25% 以上，先定位收集、排序、临时文件、计划或日志解析中的具体阶段，再决定是否优化。
- 优化不得改变项目顺序、临时文件协议、路径语义或日志兼容行为。
